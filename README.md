# Reel Insights: Global Movie Industry Analysis (TMDB)

## Project Deliverables & Structure
- **01_data_cleaning.ipynb**: Data loading, cleaning, duplicate removal, orphaned foreign key handling, and SQLite database creation.
- **02_sql_analysis.ipynb**: 10 progressive SQL queries executing multi-table joins, aggregations, and subqueries.
- **03_pandas_analysis.ipynb**: Exploratory Data Analysis using Pandas and NumPy, ROI calculations, and outlier detection.
- **04_visualizations.ipynb**: Matplotlib, Seaborn, and Plotly charts with structured business insights.
- **app.py**: Interactive Streamlit web application dashboard.

## Top 5 Overall Insights & Recommendations
1. **Budget vs Box-Office Return:** High production spend correlates with revenue, but mid-budget films often achieve higher proportional ROI, lowering financial risk.
2. **Runtime Focus:** The majority of commercially viable feature films are tightly clustered between 90 and 120 minutes.
3. **Genre Dominance:** Adventure and Action genres consistently command larger budgets and higher average gross returns.
4. **Data Integrity:** Eliminating duplicate rows and orphaned foreign keys ensures accurate SQL analytics.
5. **Strategic Action:** Production and streaming teams should leverage historical cast, crew, and keyword data for content greenlighting.
